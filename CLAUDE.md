# UMD Service Impacts

An unofficial map of the notices on <https://facilities.umd.edu/info-resources/service-impacts>.
`README.md` explains how the pieces fit; `PROMPT.md` is the daily update procedure. This file holds
the conventions and the traps.

## Two kinds of work

- **Daily data update** (most sessions): only `data/impacts.source.json` changes. Follow
  `PROMPT.md` exactly, or run the `daily-update` agent (`.claude/agents/daily-update.md`), or the
  `/update` command. Commit straight to `main`; Vercel deploys every push.
- **Site changes**: everything under `src/`. Work on a branch; every pushed branch gets a Vercel
  preview. `npm run build` must pass (it compiles the data, typechecks and bundles).

## Rules

- The site shell is constant. Never write notice data into `src/`; the page fetches
  `/data/impacts.json` at runtime.
- `public/data/` is generated by `npm run data` and gitignored. Never edit it by hand.
- Facts come only from the Facilities Management page and its attachments. When the page doesn't
  say where something is, mark it `approximate` and say why in `locationNote`; never invent dates.
- Keep the site clearly unofficial (footer and header say so). Don't use UMD logos, the
  wordmark or the Testudo mark.
- `reference/places.json` is built by `scripts/build_gazetteer.py` from OpenStreetMap (ODbL,
  credited in the map attribution). Rebuild it only when a needed building is missing, and review
  the diff.

## Look

The styling follows UMD's published brand (brand.umd.edu) without its marks:
- Colors from brand.umd.edu/colors only: Maryland Red `#e21833`, Gold `#ffd200`, black, white,
  and the grays. Status is red (in effect), gold (upcoming), medium gray (ended). Gold needs a dark
  edge on the light basemap (`edgeColor` in `impact-map.tsx`).
- Fonts from brand.umd.edu/typography, via Google Fonts: Source Sans 3 (text), Crimson Text
  (detail headlines, `font-heading`), Roboto Condensed (caps labels, `font-condensed`).
- Red is AA on white only (4.75:1). Small labels use the `eyebrow` token: red in light mode,
  gold in dark. Don't put red text on black or gold text on white.
- Square corners (`--radius: 0.125rem`), a red utility bar, black header and footer blocks.
- No UMD logo, wordmark, Testudo or state-flag pattern, and "Unofficial" stays visible.

## Traps already hit

- **MapLibre 6 loads its worker from a URL Vite can't see.** `impact-map.tsx` imports
  `maplibre-gl-worker.mjs?worker&url` and calls `setWorkerUrl`; `vite.config.ts` sets
  `worker.format: "es"`. Without both, the map is blank with "Worker failed to load".
- **`maplibre-gl.css` sets `position: relative` on the map container,** overriding Tailwind's
  `absolute inset-0`, which collapses the map to zero height. The container is an inner
  `h-full w-full` div inside the absolute wrapper.
- **`["geometry-type"]` returns `MultiPolygon`/`MultiLineString`** for multi geometries, so layer
  filters use `["in", ["geometry-type"], ["literal", [...]]]`.
- **Public Overpass servers time out often.** `build_gazetteer.py` retries three mirrors; with
  saved dumps, `--offline a.json b.json` rebuilds without the network. Query with `out geom;`, not
  `out geom tags;`, or relations (Chemistry, the Clarice, BRB) come back without outlines.
- **`shadcn add` once wrote `import { cn } from "cn"`** (and installed an npm package called
  `cn`) because `tsconfig.json` lacked `paths`. After adding components, grep for `from "cn"`.
- **Eastern offsets change with daylight saving.** `-04:00` from the second Sunday in March to the
  first Sunday in November, `-05:00` otherwise; `npm run data` rejects anything else.

## Checking visual changes

Screenshot with Playwright against `npm run build && npx vite preview`. Chromium behind the
session proxy rejects outside TLS, so route external requests through Node:
`page.route("**/*", async r => r.fulfill({ response: await r.fetch() }))`. Check 1280px and 390px,
light and dark.
